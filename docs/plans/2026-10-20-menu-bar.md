# Poképote dans la barre des menus — plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes se cochent (`- [ ]`).

**But :** le Pokémon du jour dans la barre des menus ; un clic ouvre une fenêtre à deux onglets, « Récap » (tokens du jour, messages du mois) et « Réglages ».

**Architecture :** tout le calcul vit dans `PokepetCore`, testé sans fenêtre : lire une ligne de journal (`TranscriptEntry`), cumuler par jour sans doublon (`UsageLedger`, gardé dans `~/.pokepet/usage.json`), lire seulement ce qui est nouveau (`TranscriptScanner`), puis préparer l'affichage (`Recap`, `NumberFormat`, `EvolutionProgress`). La cible `Pokepote` ne fait qu'afficher : l'icône (`MenuBarIcon`), la fenêtre (`RecapPopover`, en SwiftUI) et quelques réglages branchés sur `Loops`.

**Outils :** Swift 6.4 (SwiftPM, Swift Testing, AppKit, SwiftUI pour le contenu de la fenêtre), Command Line Tools, make.

**Spec :** [`docs/specs/2026-10-20-menu-bar-design.md`](../specs/2026-10-20-menu-bar-design.md) · spec principale : [`docs/specs/2026-10-15-pokepet-design.md`](../specs/2026-10-15-pokepet-design.md)

**Base :** `origin/main` au commit `8de17ea`, branche `feat/menu-bar`.

## Contraintes globales

- macOS 14 et plus ; Swift 6, mode strict ; aucun paquet tiers ; Command Line Tools seuls.
- Compiler et tester par le `Makefile` (`--build-system native` et le chemin du framework Swift Testing).
- Une responsabilité par fichier ; tests dans `tests/app/PokepetCore/`, en miroir ; noms de tests `@Test("…")` en français, fonctions en anglais.
- Code en anglais ; interface, messages et doc en français ; commits Conventional Commits en français, identité noreply de `hn6pot`, avec la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Source des chiffres : `~/.claude/projects/**/*.jsonl` ; rien n'est envoyé sur internet, rien n'est lu dans le trousseau.
- « Aujourd'hui » = la journée Poképote (`PokepetDay.key`, bascule à 4 h) ; « le mois » = les 7 premiers caractères de cette clé (`2026-10`).
- Toi = `entrypoint` `cli` ou `claude-desktop` ; automatique = tout le reste, y compris l'absence du champ.
- Tokens du récap = tes conversations seulement, sous-agents compris ; les automatiques n'apparaissent que sur la ligne « automatiques (à part) ».
- Un `message.id` compte une fois, avec le plus grand `output_tokens` (et `cache_read_input_tokens`) vu ; un `uuid` de message tapé compte une fois.
- Nouveau fichier `~/.pokepet/usage.json`, écrit seulement par l'app ; rien ne change dans le mod ni dans `sessions/` et `jour/`.
- L'icône : le Pokémon du jour en `Idle`, de face, environ 18 points de haut, sans lissage ; pas de chiffre, pas de « ! ».
- Aucun sprite ajouté au dépôt.
- `make install` uniquement depuis le dépôt principal, après la fusion.

## Points de vigilance

Les entrées que la spec implique et le test qui les tient :

- **Claude Code est en train d'écrire la dernière ligne quand on lit** → la ligne incomplète n'est pas lue ; elle l'est en entier au passage suivant. *Tâche 3 · `aPartialLastLineIsReadOnceComplete`*
- **La première ligne d'une réponse porte un compte partiel (3 tokens, puis 511)** → on garde le plus grand, sans compter deux fois. *Tâche 2 · `aLaterLineWithMoreTokensRaisesTheCount`*
- **Une conversation reprise recopie ses anciens messages dans un nouveau fichier** → chaque message ne compte qu'une fois. *Tâche 2 · `aMessageCopiedIntoAnotherFileCountsOnce` ; tâche 3 · `aShrunkFileIsReadAgainWithoutDoubles`*
- **Des centaines de Mo de vieux journaux à la première ouverture** → les fichiers qui n'ont pas bougé depuis le début du mois ne sont pas lus, et la lecture se fait hors du fil principal. *Tâche 3 · `filesUntouchedSinceTheStartAreSkipped` ; tâche 7 · vérification à la main*
- **`usage.json` abîmé (coupure pendant l'écriture, édition à la main)** → on repart d'un registre vide au lieu de planter. *Tâche 2 · `anUnreadableLedgerStartsEmpty`*

### Tâche 2 : Le registre des totaux par jour

**Files :**
- Create: `app/PokepetCore/UsageLedger.swift`
- Test: `tests/app/PokepetCore/UsageLedgerTests.swift`

**Interfaces :**
- Consumes : `TranscriptEntry`, `Origin` (tâche 1) ; `PokepetDay.key(_:calendar:)`.
- Produces :
  - `public struct UsageTotals: Codable, Equatable, Sendable { public var messages = 0; public var output = 0; public var cacheRead = 0 }`
  - `public struct DayUsage: Codable, Equatable, Sendable { public var you = UsageTotals(); public var automatic = UsageTotals(); public subscript(origin: Origin) -> UsageTotals { get set } }`
  - `public struct UsageLedger: Codable, Equatable, Sendable` avec :
    - `public init()`
    - `public var offsets: [String: Int]` (chemin du fichier → octets déjà lus)
    - `public private(set) var replies: [String: CountedReply]` et `public private(set) var messageDays: [String: String]` (ce qui a déjà été compté)
    - `public mutating func record(_ entry: TranscriptEntry, calendar: Calendar = .current)`
    - `public func day(_ key: String) -> DayUsage` et `public func month(_ prefix: String) -> DayUsage` (`"2026-10"`)
    - `public mutating func forgetIDs(before day: String)` (garde les totaux, oublie les identifiants des jours plus anciens)
    - `public static func load(from url: URL) -> UsageLedger` (vide si absent ou illisible) et `public func save(to url: URL) throws` (écriture atomique, crée le dossier)
  - `public struct CountedReply: Codable, Equatable, Sendable { let day: String; let origin: Origin; let output: Int; let cacheRead: Int }`

func messageCountsOnItsPokepetDay() {

}

@Test("une réponse écrite sur plusieurs lignes compte une fois")
func replyCountsOnce() {

@Test("une ligne suivante avec plus de tokens relève le compte, jamais ne le baisse")
func aLaterLineWithMoreTokensRaisesTheCount() {

@Test("toi et les automatiques sont comptés à part")
func youAndAutomaticAreSeparate() {

    ledger.record(message("u2", "2026-10-20T13:00:00.000Z", .automatic), calendar: paris)
    ledger.record(reply("msg_9", "2026-10-20T13:00:00.000Z", output: 40, .automatic), calendar: paris)
    #expect(ledger.day("2026-10-20").you == UsageTotals(messages: 1, output: 0, cacheRead: 0))

@Test("le mois additionne ses jours, et seulement les siens")
func monthAddsUpItsDays() {

    ledger.record(message("b", "2026-10-01T12:00:00.000Z"), calendar: paris)
    ledger.record(message("c", "2026-10-20T12:00:00.000Z"), calendar: paris)
    #expect(ledger.month("2026-10").you.messages == 2)
}

@Test("oublier les vieux identifiants garde les totaux")
func forgetIDsKeepsTotals() {
    var ledger = UsageLedger()
    ledger.record(reply("old", "2026-08-01T12:00:00.000Z", output: 10), calendar: paris)
    ledger.record(reply("new", "2026-10-20T12:00:00.000Z", output: 20), calendar: paris)
    ledger.forgetIDs(before: "2026-09-15")
    #expect(ledger.day("2026-08-01").you.output == 10)
    #expect(Set(ledger.replies.keys) == ["new"])
}

@Test("le registre s'enregistre et se relit à l'identique")
func saveAndLoadRoundTrip() throws {

    try Data("{\"days\":".utf8).write(to: url)
    #expect(UsageLedger.load(from: url) == UsageLedger())
}

@Test("au passage suivant, ne lit que la suite")
func readsOnlyWhatIsNew() throws {
    let file = root.appending(path: "p/s.jsonl")
    try write(replyLine("a", output: 1), to: file)
    var ledger = UsageLedger()
    let scanner = TranscriptScanner(root: root)
    scanner.scan(into: &ledger, since: since, calendar: paris)
    try append(replyLine("b", output: 10), to: file)

@Test("une dernière ligne en cours d'écriture est lue une fois complète")
func aPartialLastLineIsReadOnceComplete() throws {
    let file = root.appending(path: "p/s.jsonl")
    let line = replyLine("a", output: 5)
    try write(String(line.dropLast()), to: file)          // sans le \n final
    var ledger = UsageLedger()
    let scanner = TranscriptScanner(root: root)
    scanner.scan(into: &ledger, since: since, calendar: paris)
    #expect(ledger.day("2026-10-20").you.output == 0)
    try append("\n", to: file)
    scanner.scan(into: &ledger, since: since, calendar: paris)
    #expect(ledger.day("2026-10-20").you.output == 5)

@Test("un fichier qui rétrécit est relu depuis le début, sans doublon")

    scanner.scan(into: &ledger, since: since, calendar: paris)

@Test("un fichier supprimé garde ses totaux et sort des positions")

    #expect(ledger.day("2026-10-20").you.output == 0)
    #expect(ledger.offsets[file.path] == size(of: file))
