# Les attaques — plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes se cochent (`- [ ]`).

**But :** pendant que Claude travaille, le compagnon attaque de temps en temps (`Attack`, `Charge`, `Shoot`, `Strike`, et l'attaque propre à sa lignée), au même rythme que ses gestes, sans trembler.

**Architecture :** les attaques sont des gestes de plus. `Movement` gagne onze cas, tous dans `Movement.gestures` ; `scripts/fetch_sprites.py` les télécharge quand `AnimData.xml` les déclare. Rien d'autre ne bouge : `Loops` ne garde déjà que les gestes dont la feuille existe pour l'espèce, `Rhythm` tire dans cette liste, la zone cliquable couvre toutes les images chargées.

**Outils :** Swift 6 (SwiftPM, Swift Testing), Python 3 (`-I`), make.

**Spec :** [`docs/specs/2026-11-18-attacks-design.md`](../specs/2026-11-18-attacks-design.md) · spec principale : [`docs/specs/2026-10-15-pokepet-design.md`](../specs/2026-10-15-pokepet-design.md)

**Base :** `origin/main` au commit `5d58aa5`, branche `feat/attacks`, worktree `.worktrees/feat-attacks`.

## Points de vigilance

- **Une attaque absente pour une espèce** (Dracaufeu n'a pas `Kick`) : jamais tirée, pas de plantage. *Tâche 1 · `theGesturesOfASpeciesAreThoseItHas` ; tâche 2 · `everyPokemonHasItsSignatureAttack` ne réclame que celles de la spec.*
- **Une attaque jouée en boucle** (`Charge` est faite pour tourner) : jouée une fois comme tout geste, puis `Idle`. *Tâche 3 · vérification à la main.*
- **Le compagnon tremble** : le rythme ne change pas (15 à 30 s). *Les tests de `Rhythm` existants, inchangés.*
- **Un sprite non téléchargé alors que le code le connaît** : l'app l'ignore (`animation` rend `nil`), mais le test de la tâche 2 l'exige pour chaque espèce de la spec.
- **`CREDITS.md` périmé** : le script le régénère ; il est commité avec la tâche 2.

```swift
@Test("chaque Pokémon a les attaques communes", arguments: everySpecies)
func everyPokemonHasTheCommonAttacks(species: Species) {
    let source = PMDSprites(directory: spritesDirectory)
    for movement in [Movement.attack, .charge, .shoot, .strike] {
        #expect(source.animation(movement, species: species, direction: .front) != nil, "\(species.name) : \(movement.rawValue)")
    }
}

@Test("chaque lignée a son attaque propre", arguments: [
    (Lineage.electric, Movement.shock), (.ghost, .lick), (.water, .withdraw), (.magikarp, .spAttack),
    (.cyndaquil, .twirl), (.grass, .dance), (.fire, .kick), (.bagon, .rumble),
])
func everyLineageHasItsSignatureAttack(lineage: Lineage, movement: Movement) {
    let source = PMDSprites(directory: spritesDirectory)
    #expect(source.animation(movement, species: lineage.allSpecies[0], direction: .front) != nil, "\(lineage) : \(movement.rawValue)")
}
```
(`allSpecies[0]` est le bébé ; les cas de `Lineage` sont `fire, electric, grass, water, cyndaquil, totodile, dragon, ghost, rock, bagon, magikarp`.)
