# pokepet — plan d'implémentation

> **Pour les agents :** sous-skill requis : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes se cochent (`- [ ]`).

**But :** Poképote, un compagnon Pokémon qui flotte sur l'écran du Mac et montre l'état des conversations Claude Code, alimenté par le mod `pokepet`.

**Architecture :** le mod (TypeScript) écrit un fichier par conversation et un compteur par jour dans `~/.pokepet/` ; l'app (Swift) les relit chaque seconde. Toute la décision vit dans `PokepetCore`, testé sans fenêtre ; la cible AppKit `Pokepote` ne fait qu'appliquer.

**Outils :** Swift 6.4 (SwiftPM, Swift Testing, AppKit, Command Line Tools), mod Claude Code 2.1.29x (`claude plugin test`), Python 3 (script des sprites), make, launchd.

**Spec :** [`docs/specs/2026-10-15-pokepet-design.md`](../specs/2026-10-15-pokepet-design.md) · décisions : [`docs/cadrage.md`](../cadrage.md)

**Répétition à blanc (15/10) :** tout le code de ce plan a été écrit et lancé hors du dépôt : 75 tests Swift et 23 tests du mod passent, l'app tourne, le bundle se signe.

## Contraintes globales

- macOS 14 et plus ; Swift 6 (outils 6.0, mode strict) ; aucun paquet tiers ; Command Line Tools seuls (pas d'Xcode).
- Compiler et tester par le `Makefile` : `--build-system native` et le chemin du framework Swift Testing.
- Une responsabilité par fichier ; tests dans `tests/`, en miroir (`tests/app/PokepetCore/`, `tests/mod/hooks/`).
- Nom affiché « Poképote » ; identifiants `Pokepote`, `com.hn6pot.pokepote` ; projet, mod et dossier `pokepet` (`~/.pokepet/`).
- Contrat de fichiers de la spec § 3, à l'octet près : `etat` ∈ travaille, attend, fini, echec, fermee ; `majLe` UTC sans millisecondes.
- Le lien ouvert est toujours de la forme `claude://code/continue?session=local_[A-Za-z0-9-]{1,64}`.
- Journée : date locale, bascule à 4 h ; stades à 8 et 20 réponses ; périmé après 2 h sauf `attend` ; sommeil après 15 min.
- Taille de 30 à 300 % ; 100 % = pixels ×3, sans lissage.
- Sprites SpriteCollab au commit `e7868e9a7f6b931d1fb826756a490d4633879d03`, commités ; licence CC BY-NC 4.0 : dépôt privé, usage non commercial, `CREDITS.md`.
- Le mod appelle toujours `next(e)`, n'affiche rien, n'écrit rien sans interface, et avale ses erreurs.

## Points de vigilance

Les entrées que la spec implique sans les tester ailleurs, et le test qui les tient :

- **Un autre programme écrit un lien piégé dans ~/.pokepet** → l'app n'ouvre que `claude://code/continue?session=local_…`. *Tâche 3 · `unLienDeFormeInattendueNEstJamaisOuvert` (https, UUID, paramètre en plus, code/new)*
- **Le mod est en train d'écrire quand l'app lit** → le fichier illisible est ignoré cette seconde-là, jamais supprimé. *Tâches 3 et 4 · `unFichierIllisibleEstIgnoreSansEtreSupprime`, `garderIgnorerEtSupprimer`*
- **Une conversation plante en attendant** → le pid mort fait disparaître l'attente, la bulle « ! » ne reste pas pour toujours. *Tâches 3 et 4 · `unProcessusMortFaitSupprimerMemeEnAttente`, `unProcessusTermineEstMort`*
- **Le changement d'heure, minuit et 4 h** → le même jour des deux côtés, donc le même bébé et le bon compteur. *Tâches 2 et 5 · `lePassageALHeureDeteNeDecalePasLaBascule`, `leRetourALHeureDHiver…`, `le premier du mois avant 4 h…`*
- **Un écran débranché depuis la dernière fois** → Poképote revient en bas à droite de l'écran principal. *Tâche 11 · vérification à la main (`placerFenetre`) : `defaults write Pokepote position -array 9000 9000`, puis `make run`*

```swift
/// Le stade d'évolution, déduit du nombre de réponses de Claude dans la journée.
public enum Stade: Int, Comparable, Sendable {
    case un = 1
    case deux = 2
    case trois = 3

    public static let seuilDeux = 8
    public static let seuilTrois = 20

    public init(reponses: Int) {
        if reponses >= Self.seuilTrois {
            self = .trois
        } else if reponses >= Self.seuilDeux {
            self = .deux
        } else {
            self = .un
        }
    }

    public static func < (a: Stade, b: Stade) -> Bool { a.rawValue < b.rawValue }
}
```

```swift
import Foundation

/// La journée de pokepet commence à 4 h du matin, heure locale : à 3 h 59 le 16, on est encore le 15.
public enum Journee {
    public static let heureDeBascule = 4

    /// La journée en cours à l'instant `date`, écrite "AAAA-MM-JJ".
    public static func cle(_ date: Date, calendrier: Calendar = .current) -> String {
        let c = calendrier.dateComponents([.year, .month, .day, .hour], from: date)
        var jour = calendrier.date(from: DateComponents(year: c.year, month: c.month, day: c.day))!
        if c.hour! < heureDeBascule {
            jour = calendrier.date(byAdding: .day, value: -1, to: jour)!
        }
        let j = calendrier.dateComponents([.year, .month, .day], from: jour)
        return String(format: "%04d-%02d-%02d", j.year!, j.month!, j.day!)
    }
}
```

Créer `app/PokepetCore/TirageDuJour.swift` :

```swift
/// Tire la lignée du jour à partir de la date : même date, même bébé, sans rien stocker.
/// Le `hashValue` de Swift change à chaque lancement : on calcule notre propre empreinte (FNV-1a),
/// puis on la mélange (fmix32 de MurmurHash3), sinon les jours alterneraient feu, électrik, feu…
public enum TirageDuJour {
    public static func lignee(pour cle: String) -> Lignee {
        melanger(fnv1a(cle)) & 1 == 0 ? .feu : .electrik
    }

    static func fnv1a(_ texte: String) -> UInt32 {
        var h: UInt32 = 2_166_136_261
        for octet in texte.utf8 {
            h ^= UInt32(octet)
            h = h &* 16_777_619
        }
        return h
    }

    static func melanger(_ valeur: UInt32) -> UInt32 {
        var h = valeur
        h ^= h >> 16
        h = h &* 0x85EB_CA6B
        h ^= h >> 13
        h = h &* 0xC2B2_AE35
        h ^= h >> 16
        return h
    }
}
```

```swift
import Foundation

/// Ce que l'app fait d'un fichier de session.
public enum Decision: Equatable, Sendable {
    case garder, ignorer, supprimer
}

/// Les règles de lecture des fichiers de session (spec § 3).
public enum TriSessions {
    public static let peremption: TimeInterval = 2 * 3600

    /// `session` vaut `nil` quand le fichier est illisible : on l'ignore sans le supprimer
    /// (le mod est peut-être en train de l'écrire).
    public static func decider(
        _ session: EtatSession?, maintenant: Date, pidVivant: (Int32) -> Bool
    ) -> Decision {
        guard let session else { return .ignorer }
        if session.etat == .fermee || !pidVivant(session.pid) { return .supprimer }
        if session.etat != .attend && maintenant.timeIntervalSince(session.majLe) > peremption {
            return .ignorer
        }
        return .garder
    }
}
```

```swift
import Foundation

/// Ce que montre le compagnon, du moins au plus urgent.
public enum Affichage: Int, Comparable, Sendable {
    case repos, fini, travaille, echec, attend

    public static func < (a: Affichage, b: Affichage) -> Bool { a.rawValue < b.rawValue }
}

/// L'état à montrer, et la conversation à ouvrir au clic s'il y en a une.
public struct Urgence: Equatable, Sendable {
    public let affichage: Affichage
    public let lien: String?

    public init(affichage: Affichage, lien: String?) {
        self.affichage = affichage
        self.lien = lien
    }

    public static let repos = Urgence(affichage: .repos, lien: nil)
}

public enum EtatLePlusUrgent {

    public static func calculer(_ sessions: [EtatSession]) -> Urgence {
        guard let pire = sessions.map({ affichage(de: $0.etat) }).max() else { return .repos }
        guard pire == .attend else { return Urgence(affichage: pire, lien: nil) }
        let lien = sessions
            .filter { $0.etat == .attend && $0.lien.map(estAccepte) == true }
            .max { $0.majLe < $1.majLe }?
            .lien
        return Urgence(affichage: .attend, lien: lien)
    }

    /// N'importe quel programme peut écrire dans ~/.pokepet : on n'ouvre que ce lien-là.
    static func estAccepte(_ lien: String) -> Bool {
        lien.wholeMatch(of: /claude:\/\/code\/continue\?session=local_[A-Za-z0-9-]{1,64}/) != nil
    }

    static func affichage(de etat: Etat) -> Affichage {
        switch etat {
        case .attend: .attend
        case .echec: .echec
        case .travaille: .travaille
        case .fini: .fini
        case .fermee: .repos
        }
    }
}
```

```swift
import Darwin
import Foundation

/// Lit `~/.pokepet/` : les sessions (en supprimant les fichiers condamnés) et les compteurs du jour.
public struct LectureDossier: Sendable {
    public let racine: URL

    public init(racine: URL) {
        self.racine = racine
    }

    public static var parDefaut: LectureDossier {
        LectureDossier(racine: FileManager.default.homeDirectoryForCurrentUser.appending(path: ".pokepet"))
    }

    /// Les sessions à prendre en compte ; supprime au passage celles que `TriSessions` condamne.
    public func sessions(maintenant: Date, pidVivant: (Int32) -> Bool = LectureDossier.pidVivant) -> [EtatSession] {
        fichiersJSON(dans: racine.appending(path: "sessions")).compactMap { url in
            let session = (try? Data(contentsOf: url)).flatMap(EtatSession.decoder)
            switch TriSessions.decider(session, maintenant: maintenant, pidVivant: pidVivant) {
            case .garder: return session
            case .ignorer: return nil
            case .supprimer:
                try? FileManager.default.removeItem(at: url)
                return nil
            }
        }
    }

    /// Le contenu brut des fichiers `jour/<journee>/*.json` ; vide si le dossier n'existe pas.
    public func compteurs(journee: String) -> [Data] {
        fichiersJSON(dans: racine.appending(path: "jour").appending(path: journee))
            .compactMap { try? Data(contentsOf: $0) }
    }

    /// Vrai si un processus porte ce numéro (EPERM : il existe mais appartient à un autre utilisateur).
    public static func pidVivant(_ pid: Int32) -> Bool {
        pid > 0 && (kill(pid, 0) == 0 || errno == EPERM)
    }

    private func fichiersJSON(dans dossier: URL) -> [URL] {
        let contenu = (try? FileManager.default.contentsOfDirectory(at: dossier, includingPropertiesForKeys: nil)) ?? []
        return contenu.filter { $0.pathExtension == "json" }
    }
}
```

```typescript
/** La journée de pokepet commence à 4 h, heure locale : à 3 h 59 le 16, on est encore le 15. */
export const HEURE_DE_BASCULE = 4

/** La journée en cours à l'instant `ms`, écrite "AAAA-MM-JJ" (même règle que Journee.swift). */
export function cleJournee(ms: number): string {
  const d = new Date(ms)
  if (d.getHours() < HEURE_DE_BASCULE) d.setDate(d.getDate() - 1)
  const deux = (n: number) => String(n).padStart(2, '0')
  return `${d.getFullYear()}-${deux(d.getMonth() + 1)}-${deux(d.getDate())}`
}
```

```typescript
/** Ce que le mod écrit d'une conversation (le même vocabulaire qu'EtatSession.swift). */
export type Etat = 'travaille' | 'attend' | 'fini' | 'echec' | 'fermee'

/** Pourquoi un tour s'est terminé, comme `turn.complete` le dit. */
export type Raison = 'answer' | 'aborted' | 'refusal' | 'error'

/** Les outils qui attendent une réponse de toi : une question, ou l'approbation d'un plan. */
export const OUTILS_QUI_ATTENDENT: readonly string[] = ['AskUserQuestion', 'ExitPlanMode']

export function etatDeFin(raison: Raison): Etat {
  return raison === 'error' || raison === 'refusal' ? 'echec' : 'fini'
}

/** Seule une réponse menée à son terme compte pour l'évolution ; une interruption ne compte pas. */
export function compte(raison: Raison): boolean {
  return raison === 'answer'
}

/** Le lien Desktop, à partir de CLAUDE_CODE_HOST_SESSION_ID ; rien hors de l'app Desktop. */
export function lienDesktop(idHote: string | undefined): string | undefined {
  return idHote !== undefined && /^local_[A-Za-z0-9-]{1,64}$/.test(idHote)
    ? `claude://code/continue?session=${idHote}`
    : undefined
}

/** Le contenu de `sessions/<id>.json`. L'heure est écrite sans millisecondes : c'est ce que Swift lit. */
export function contenuSession(etat: Etat, ms: number, pid: number, lien: string | undefined): string {
  const majLe = new Date(ms).toISOString().replace(/\.\d{3}Z$/, 'Z')
  return JSON.stringify(lien === undefined ? { etat, majLe, pid } : { etat, majLe, pid, lien })
}

/** Le compteur suivant, à partir du contenu actuel de `jour/<date>/<id>.json` (absent ou cassé : zéro). */
export function compteurSuivant(contenu: string | undefined): string {
  let reponses = 0
  try {
    const lu = contenu === undefined ? undefined : JSON.parse(contenu)
    if (typeof lu?.reponses === 'number' && lu.reponses > 0) reponses = lu.reponses
  } catch {
    reponses = 0
  }
  return JSON.stringify({ reponses: reponses + 1 })
}
```

```typescript
/** Écrit `~/.pokepet/sessions/<id>.json`. */
export async function ecrireEtat($: EngineInterface, etat: Etat): Promise<void> {
  const chemin = `${await racine($)}/sessions/${await $.session.id()}.json`
  const pid = Number((await $.env.get('CLAUDE_PID')) ?? 0)

  await $.fs.write(chemin, contenuSession(etat, await $.clock.now(), pid, lien))
}

/** Ajoute une réponse à `~/.pokepet/jour/<date>/<id>.json`. Seule cette conversation écrit ce fichier. */
export async function compterUneReponse($: EngineInterface): Promise<void> {
  const chemin = `${await racine($)}/jour/${cleJournee(await $.clock.now())}/${await $.session.id()}.json`
  const actuel = (await $.fs.exists(chemin)) ? String(await $.fs.read(chemin)) : undefined
  await $.fs.write(chemin, compteurSuivant(actuel))
```

```typescript
import type { EngineInterface, Register } from 'claude-code'
import { compte, etatDeFin, OUTILS_QUI_ATTENDENT, type Etat } from './etat'
import { compterUneReponse, ecrireEtat } from './fichiers'
import { aUneInterface } from './interface'

// Le dernier état écrit, pour n'écrire que les changements. Repart de zéro si le mod est rechargé.
let dernier: Etat | undefined

/** Écrit l'état s'il a changé et si la conversation a une interface ; n'échoue jamais. */
async function noter($: EngineInterface, etat: Etat): Promise<void> {
  try {
    if (etat === dernier || !(await aUneInterface($))) return
    await ecrireEtat($, etat)
    dernier = etat
  } catch {
    // Disque plein, dossier interdit… : le compagnon se trompera, la conversation continue.
  }
}

/** Ajoute une réponse au compteur du jour ; n'échoue jamais. */
async function compter($: EngineInterface): Promise<void> {
  try {
    if (await aUneInterface($)) await compterUneReponse($)
  } catch {
    // Comme pour noter.
  }
}

/**
 * Branche les événements de Claude Code sur l'écriture des fichiers de ~/.pokepet/ (spec § 4).
 * Chaque crochet appelle toujours `next(e)` : le mod ne change jamais le cours d'une conversation.
 */
export const register: Register = on => {
  dernier = undefined

  on('turn.start', async ($, e, next) => {
    await noter($, 'travaille')
    return next(e)
  })

  on('tool.call', async ($, e, next) => {
    // Les outils des sous-agents ne parlent pas pour la conversation.
    if (e.agentId !== undefined) return next(e)
    if (OUTILS_QUI_ATTENDENT.includes(e.tool)) await noter($, 'attend')
    const resultat = await next(e)
    // L'outil a rendu la main : la question a sa réponse, ou la permission a été donnée ou refusée.
    if (dernier === 'attend') await noter($, 'travaille')
    return resultat
  }).catch(($, e, next) => next(e))

  // Le moteur décide si un outil peut tourner ; « ask » veut dire qu'une permission va t'être demandée.
  // (Un événement du moteur, pas le crochet classique PermissionRequest, qui ne tourne pas
  // quand une organisation gère Claude Code.)
  on('tool.check', async ($, e, next) => {
    const verdict = await next(e)
    if (verdict.decision === 'ask' && e.tool_use_id !== undefined && e.agentId === undefined) {
      await noter($, 'attend')
    }
    return verdict
  }).catch(($, e, next) => next(e))

  on('turn.complete', async ($, e, next) => {
    if (e.agentId !== undefined) return next(e)
    await noter($, etatDeFin(e.reason))
    if (compte(e.reason)) await compter($)
    return next(e)
  })

  on('session.end', async ($, e, next) => {
    await noter($, 'fermee')
    return next(e)
  })
}
```

```python
#!/usr/bin/env python3
"""Récupère les sprites des six Pokémon depuis PMDCollab/SpriteCollab, à un commit figé,
dans sprites/pmd/<numéro>/, et régénère CREDITS.md. À lancer à la main : python3 -I scripts/recuperer-sprites.py
Le résultat est commité ; l'app ne télécharge jamais rien."""

import pathlib
import re
import urllib.request

COMMIT = "e7868e9a7f6b931d1fb826756a490d4633879d03"  # master du 15/10/2026
SOURCE = f"https://raw.githubusercontent.com/PMDCollab/SpriteCollab/{COMMIT}"
POKEMON = {"0004": "Salamèche", "0005": "Reptincel", "0006": "Dracaufeu",
           "0172": "Pichu", "0025": "Pikachu", "0026": "Raichu"}
ANIMATIONS = ["Idle", "Walk", "Charge", "Hop", "Rotate", "Hurt", "Sleep"]
RACINE = pathlib.Path(__file__).resolve().parent.parent


def telecharger(chemin: str) -> bytes:
    with urllib.request.urlopen(f"{SOURCE}/{chemin}", timeout=30) as reponse:
        return reponse.read()


def planche(animdata: str, nom: str) -> str:
    """Le nom de la planche PNG d'une animation : la sienne, ou celle qu'elle copie (CopyOf)."""
    bloc = re.search(rf"<Anim>\s*<Name>{nom}</Name>(.*?)</Anim>", animdata, re.S)
    if bloc is None:
        raise SystemExit(f"animation {nom} absente")
    copie = re.search(r"<CopyOf>(\w+)</CopyOf>", bloc.group(1))
    return copie.group(1) if copie else nom


def noms_des_auteurs() -> dict[str, str]:
    lignes = telecharger("credit_names.txt").decode().splitlines()[1:]
    return {colonnes[1]: colonnes[0] for colonnes in (l.split("\t") for l in lignes) if len(colonnes) >= 2}


def main() -> None:
    noms = noms_des_auteurs()
    credits = ["# Crédits des sprites", "",
               f"Sprites de [PMD SpriteCollab](https://github.com/PMDCollab/SpriteCollab), commit `{COMMIT}`.",
               "Bases : Pokémon Mystery Dungeon (Chunsoft). Ajouts de la communauté sous licence",
               "[CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) (usage non commercial, crédit obligatoire).",
               ""]
    for numero, nom in POKEMON.items():
        dossier = RACINE / "sprites" / "pmd" / numero
        dossier.mkdir(parents=True, exist_ok=True)
        animdata = telecharger(f"sprite/{numero}/AnimData.xml").decode()
        (dossier / "AnimData.xml").write_text(animdata)
        for planche_png in sorted({planche(animdata, a) for a in ANIMATIONS}):
            (dossier / f"{planche_png}-Anim.png").write_bytes(telecharger(f"sprite/{numero}/{planche_png}-Anim.png"))
        auteurs: dict[str, set[str]] = {}
        for ligne in telecharger(f"sprite/{numero}/credits.txt").decode().splitlines():
            colonnes = ligne.split("\t")
            if len(colonnes) >= 5 and set(colonnes[4].split(",")) & set(ANIMATIONS):
                auteurs.setdefault(noms.get(colonnes[1], colonnes[1]), set()).add(colonnes[3])
        credits.append(f"- **{nom}** (`{numero}`) : " + ", ".join(
            f"{auteur} ({', '.join(sorted(licences))})" for auteur, licences in sorted(auteurs.items())))
        print(f"{numero} {nom} : ok")
    (RACINE / "CREDITS.md").write_text("\n".join(credits) + "\n")


if __name__ == "__main__":
    main()
```

```swift
    public let hauteur: Int
    /// En 1/60 de seconde.
    public let durees: [Int]
}

/// Lit le fichier `AnimData.xml` de SpriteCollab.
public enum AnimData {
    public static func lire(_ donnees: Data) -> [String: AnimationPMD] {
        let analyseur = Analyseur()
        let parseur = XMLParser(data: donnees)
        parseur.delegate = analyseur
        guard parseur.parse() else { return [:] }
        var resultat: [String: AnimationPMD] = [:]
        for brute in analyseur.brutes {
            let source = brute.copieDe.flatMap { nom in analyseur.brutes.first { $0.nom == nom } } ?? brute
            guard let largeur = source.largeur, let hauteur = source.hauteur, !source.durees.isEmpty else { continue }
            resultat[brute.nom] = AnimationPMD(
                nom: brute.nom, planche: source.nom, largeur: largeur, hauteur: hauteur, durees: source.durees)
        }
        return resultat
    }

    private struct Brute {
        var nom = ""
        var copieDe: String?
        var largeur: Int?
        var hauteur: Int?
        var durees: [Int] = []
    }

    private final class Analyseur: NSObject, XMLParserDelegate {
        var brutes: [Brute] = []
        private var courante: Brute?
        private var texte = ""

        func parser(_ p: XMLParser, didStartElement nom: String, namespaceURI: String?, qualifiedName: String?, attributes: [String: String] = [:]) {
            if nom == "Anim" { courante = Brute() }
            texte = ""
        }

        func parser(_ p: XMLParser, foundCharacters chaine: String) {
            texte += chaine
        }

        func parser(_ p: XMLParser, didEndElement nom: String, namespaceURI: String?, qualifiedName: String?) {
            let valeur = texte.trimmingCharacters(in: .whitespacesAndNewlines)
            switch nom {
            case "Name": courante?.nom = valeur
            case "CopyOf": courante?.copieDe = valeur
            case "FrameWidth": courante?.largeur = Int(valeur)
            case "FrameHeight": courante?.hauteur = Int(valeur)
            case "Duration": if let d = Int(valeur) { courante?.durees.append(d) }
            case "Anim":
                if let courante { brutes.append(courante) }
                courante = nil
            default: break
            }
        }
    }
}
```

```swift
import Foundation

/// Le minutage d'une animation : quelle image montrer après tant de temps.
public struct Lecteur: Sendable {
    /// En 1/60 de seconde, une durée par image.
    public let durees: [Int]
    public let enBoucle: Bool

    public init(durees: [Int], enBoucle: Bool) {
        self.durees = durees.map { max($0, 1) }
        self.enBoucle = enBoucle
    }

    private var total: Int { durees.reduce(0, +) }

    /// L'index de l'image à montrer `ecoule` secondes après le début. Une animation jouée une fois
    /// reste sur sa dernière image.
    public func image(apres ecoule: TimeInterval) -> Int {
        guard !durees.isEmpty else { return 0 }
        var tic = Int(max(ecoule, 0) * 60)
        if enBoucle {
            tic %= total
        } else if tic >= total {
            return durees.count - 1
        }
        for (index, duree) in durees.enumerated() {
            if tic < duree { return index }
            tic -= duree
        }
        return durees.count - 1
    }

    /// Vrai quand une animation jouée une fois est allée au bout ; jamais pour une boucle.
    public func estFinie(apres ecoule: TimeInterval) -> Bool {
        !enBoucle && Int(max(ecoule, 0) * 60) >= total
    }
}
```

```swift
import CoreGraphics

/// Les mouvements que le compagnon sait faire, du nom des animations PMD.
public enum Mouvement: String, CaseIterable, Sendable {
    case idle = "Idle", walk = "Walk", charge = "Charge", hop = "Hop"
    case rotate = "Rotate", hurt = "Hurt", sleep = "Sleep"
}

/// Les directions utilisées : les lignes d'une planche PMD vont dans cet ordre
/// (bas, bas-droite, droite, haut-droite, haut, haut-gauche, gauche, bas-gauche).
public enum Direction: Int, Sendable {
    case face = 0
    case droite = 2
    case gauche = 6
}

/// Une animation prête à dessiner : ses images et leurs durées (1/60 s).
public struct AnimationChargee {
    public let images: [CGImage]
    public let durees: [Int]

    public init(images: [CGImage], durees: [Int]) {
        self.images = images
        self.durees = durees
    }
}

/// Le contrat d'une source de sprites. L'app ne connaît que lui : changer de source
/// (PMD aujourd'hui, autre chose demain) ne touche pas au reste.
public protocol SourceSprites: AnyObject {
    /// `nil` si ce Pokémon n'a pas cette animation.
    func animation(_ mouvement: Mouvement, espece: Espece, direction: Direction) -> AnimationChargee?
}

extension SourceSprites {
    /// L'animation demandée, ou à défaut le repos (`Idle`).
    public func animationOuRepos(_ mouvement: Mouvement, espece: Espece, direction: Direction) -> AnimationChargee? {
        animation(mouvement, espece: espece, direction: direction)
            ?? animation(.idle, espece: espece, direction: .face)
    }
}
```

```swift
import CoreGraphics
import Foundation
import ImageIO

/// La source PMD SpriteCollab : `<dossier>/<numéro>/AnimData.xml` et les planches `<nom>-Anim.png`.
public final class SpritesPMD: SourceSprites {
    private let dossier: URL
    private var animData: [String: [String: AnimationPMD]] = [:]
    private var cache: [String: AnimationChargee] = [:]

    public init(dossier: URL) {
        self.dossier = dossier
    }

    public func animation(_ mouvement: Mouvement, espece: Espece, direction: Direction) -> AnimationChargee? {
        let cle = "\(espece.numero)/\(mouvement.rawValue)/\(direction.rawValue)"
        if let deja = cache[cle] { return deja }
        guard let pmd = animations(de: espece)[mouvement.rawValue],
              let planche = chargerPNG(dossier.appending(path: espece.numero).appending(path: "\(pmd.planche)-Anim.png"))
        else { return nil }
        let lignes = planche.height / pmd.hauteur
        // Certaines animations (Sleep) n'ont qu'une ligne : on prend la première.
        let ligne = direction.rawValue < lignes ? direction.rawValue : 0
        let images = (0..<pmd.durees.count).compactMap { colonne in
            planche.cropping(to: CGRect(x: colonne * pmd.largeur, y: ligne * pmd.hauteur, width: pmd.largeur, height: pmd.hauteur))
        }
        guard images.count == pmd.durees.count else { return nil }
        let chargee = AnimationChargee(images: images, durees: pmd.durees)
        cache[cle] = chargee
        return chargee
    }

    private func animations(de espece: Espece) -> [String: AnimationPMD] {
        if let deja = animData[espece.numero] { return deja }
        let url = dossier.appending(path: espece.numero).appending(path: "AnimData.xml")
        let lues = (try? Data(contentsOf: url)).map(AnimData.lire) ?? [:]
        animData[espece.numero] = lues
        return lues
    }

    private func chargerPNG(_ url: URL) -> CGImage? {
        guard let source = CGImageSourceCreateWithURL(url as CFURL, nil) else { return nil }
        return CGImageSourceCreateImageAtIndex(source, 0, nil)
    }
}
```

```swift
import Foundation

/// Ce que l'app doit montrer à un instant donné.
public struct Apparence: Equatable, Sendable {
    public let espece: Espece
    public let stade: Stade
    public let reponses: Int
    /// L'animation de fond, jouée en boucle.
    public let fond: Mouvement
    /// Une animation à jouer une fois avant de revenir au fond (`Rotate` en finissant, `Hurt` en échouant).
    public let interlude: Mouvement?
    /// Le flash blanc d'une évolution ou d'un nouveau bébé.
    public let flash: Bool
    /// La bulle « ! » quand une conversation attend.
    public let bulle: Bool
    /// Vrai quand le compagnon peut se promener (repos, fini ou échec, et éveillé).
    public let peutSeBalader: Bool
    /// La conversation à ouvrir au clic.
    public let lien: String?
}

/// Le « cerveau » : à partir de l'heure, de l'état le plus urgent et du compteur du jour,
/// décide quel Pokémon montrer et comment. Appelé une fois par seconde.
public struct Compagnon: Sendable {
    public static let delaiSommeil: TimeInterval = 15 * 60

    private let lancement: Date
    private var precedent: (affichage: Affichage, espece: Espece)?

    public init(lancement: Date) {
        self.lancement = lancement
    }

    /// `derniereActivite` : la plus récente mise à jour (`majLe`) parmi les sessions gardées.
    public mutating func mettreAJour(
        maintenant: Date, urgence: Urgence, reponses: Int, derniereActivite: Date?, calendrier: Calendar = .current
    ) -> Apparence {
        let stade = Stade(reponses: reponses)
        let espece = TirageDuJour.lignee(pour: Journee.cle(maintenant, calendrier: calendrier)).espece(au: stade)
        let affichage = urgence.affichage

        var interlude: Mouvement?
        var flash = false
        if let precedent {
            flash = precedent.espece != espece
            if precedent.affichage != affichage {
                interlude = affichage == .fini ? .rotate : affichage == .echec ? .hurt : nil
            }
        }
        precedent = (affichage, espece)

        let repos = [.repos, .fini, .echec].contains(affichage)
        let depuis = max(derniereActivite ?? lancement, lancement)
        let endormi = repos && maintenant.timeIntervalSince(depuis) > Self.delaiSommeil
        let fond: Mouvement = switch affichage {
        case .attend: .hop
        case .travaille: .charge
        case .repos, .fini, .echec: endormi ? .sleep : .idle
        }

        return Apparence(
            espece: espece, stade: stade, reponses: reponses, fond: fond, interlude: interlude, flash: flash,
            bulle: affichage == .attend, peutSeBalader: repos && !endormi, lien: urgence.lien)
    }
}
```

```swift
    var etat: UInt64
    mutating func next() -> UInt64 {
        etat &+= 0x9E37_79B9_7F4A_7C15
        var z = etat
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
```

```swift
import CoreGraphics
import Foundation

/// Un pas de promenade : un déplacement horizontal (0 = une pause) et sa durée.
public struct Pas: Equatable, Sendable {
    public let deplacement: CGFloat
    public let duree: TimeInterval
}

/// Décide la promenade au repos : des pauses et quelques pas à gauche ou à droite, sans sortir des bornes.
public enum Balade {
    /// Points par seconde.
    public static let vitesse: CGFloat = 30

    /// `x` : la position actuelle ; `minimum`/`maximum` : les bornes de l'écran pour la fenêtre.
    public static func prochainPas(
        x: CGFloat, minimum: CGFloat, maximum: CGFloat, hasard: inout some RandomNumberGenerator
    ) -> Pas {
        if Bool.random(using: &hasard) {
            return Pas(deplacement: 0, duree: TimeInterval.random(in: 2...6, using: &hasard))
        }
        var distance = CGFloat.random(in: 20...80, using: &hasard) * (Bool.random(using: &hasard) ? 1 : -1)
        if x + distance > maximum || x + distance < minimum { distance = -distance }
        let arrivee = min(max(x + distance, minimum), maximum)
        let deplacement = arrivee - x
        return Pas(deplacement: deplacement, duree: TimeInterval(abs(deplacement) / vitesse))
    }
}
```

```swift
import CoreGraphics

/// Dit si un point tombe sur un pixel visible du sprite, pour laisser passer les clics dans le vide.
public enum ZoneCliquable {
    /// `x`, `y` : en pixels de l'image, origine en haut à gauche.
    public static func estOpaque(_ image: CGImage, x: Int, y: Int) -> Bool {
        guard (0..<image.width).contains(x), (0..<image.height).contains(y) else { return false }
        var pixel: [UInt8] = [0, 0, 0, 0]
        let ok = pixel.withUnsafeMutableBytes { octets -> Bool in
            guard let contexte = CGContext(
                data: octets.baseAddress, width: 1, height: 1, bitsPerComponent: 8, bytesPerRow: 4,
                space: CGColorSpaceCreateDeviceRGB(), bitmapInfo: CGImageAlphaInfo.premultipliedLast.rawValue)
            else { return false }
            // Le contexte a son origine en bas à gauche : on décale l'image pour amener (x, y) en (0, 0).
            contexte.draw(image, in: CGRect(x: -x, y: y - image.height + 1, width: image.width, height: image.height))
            return true
        }
        return ok && pixel[3] > 0
    }
}
```

```swift
import CoreGraphics

/// La position et la taille retenues d'un lancement à l'autre.
public final class Reglages {
    public static let tailleMin = 0.3
    public static let tailleMax = 3.0
    /// À 100 %, un pixel du sprite fait 3 points.
    public static let pixelsParPoint = 3.0

    private let defaults: UserDefaults

    public init(defaults: UserDefaults) {
        self.defaults = defaults
    }

    public static func borner(_ taille: Double) -> Double {
        min(max(taille, tailleMin), tailleMax)
    }

    /// 1.0 = 100 %.
    public var taille: Double {
        get { defaults.object(forKey: "taille") == nil ? 1 : Self.borner(defaults.double(forKey: "taille")) }
        set { defaults.set(Self.borner(newValue), forKey: "taille") }
    }

    /// Le coin bas-gauche de la fenêtre, en coordonnées d'écran ; `nil` au premier lancement.
    public var position: CGPoint? {
        get {
            guard let xy = defaults.array(forKey: "position") as? [Double], xy.count == 2 else { return nil }
            return CGPoint(x: xy[0], y: xy[1])
        }
        set { defaults.set(newValue.map { [Double($0.x), Double($0.y)] }, forKey: "position") }
    }
}
```

```swift
import AppKit
import PokepetCore

/// Dessine l'image courante, agrandie sans lissage, la bulle « ! » et le flash blanc.
/// Transmet la souris aux `Gestes`.
final class VueSprite: NSView {
    var image: CGImage? { didSet { needsDisplay = true } }
    /// Points d'écran par pixel du sprite.
    var echelle: CGFloat = 3 { didSet { needsDisplay = true } }
    var bulle = false { didSet { needsDisplay = true } }
    /// Opacité du flash blanc, de 0 à 1.
    var flash: CGFloat = 0 { didSet { needsDisplay = true } }
    /// La hauteur réservée au-dessus du sprite pour la bulle.
    var hauteurBulle: CGFloat { 12 * echelle }
    var gestes: Gestes?

    /// Le rectangle où le sprite est dessiné : centré dans la zone sous la bulle.
    var cadreSprite: CGRect {
        guard let image else { return .zero }
        let largeur = CGFloat(image.width) * echelle, hauteur = CGFloat(image.height) * echelle
        let zone = CGRect(x: 0, y: 0, width: bounds.width, height: bounds.height - hauteurBulle)
        return CGRect(x: zone.midX - largeur / 2, y: zone.midY - hauteur / 2, width: largeur, height: hauteur)
    }

    override func draw(_ dirtyRect: NSRect) {
        guard let contexte = NSGraphicsContext.current?.cgContext, let image else { return }
        contexte.interpolationQuality = .none
        let cadre = cadreSprite
        contexte.draw(image, in: cadre)
        if flash > 0 {
            contexte.saveGState()
            contexte.clip(to: cadre, mask: image)
            contexte.setFillColor(NSColor.white.withAlphaComponent(flash).cgColor)
            contexte.fill(cadre)
            contexte.restoreGState()
        }
        if bulle { dessinerBulle(au: CGPoint(x: cadre.midX, y: cadre.maxY)) }
    }

    private func dessinerBulle(au pied: CGPoint) {
        let rayon = 5 * echelle
        let rond = CGRect(x: pied.x - rayon, y: pied.y, width: rayon * 2, height: rayon * 2)
        NSColor.white.setFill()
        NSBezierPath(ovalIn: rond).fill()
        NSColor.black.setStroke()
        let contour = NSBezierPath(ovalIn: rond.insetBy(dx: 1, dy: 1))
        contour.lineWidth = 2
        contour.stroke()
        let texte = NSAttributedString(string: "!", attributes: [
            .font: NSFont.boldSystemFont(ofSize: rayon * 1.4), .foregroundColor: NSColor.systemRed,
        ])
        let taille = texte.size()
        texte.draw(at: CGPoint(x: rond.midX - taille.width / 2, y: rond.midY - taille.height / 2))
    }

    /// Vrai si le point (coordonnées de la vue) tombe sur un pixel visible du sprite.
    func toucheLeSprite(_ point: CGPoint) -> Bool {
        guard let image else { return false }
        let cadre = cadreSprite
        guard cadre.contains(point) else { return false }
        let x = Int((point.x - cadre.minX) / echelle)
        let y = Int((cadre.maxY - point.y) / echelle)
        return ZoneCliquable.estOpaque(image, x: x, y: y)
    }

    /// Le premier clic agit tout de suite, même si Poképote n'est pas l'app active.
    override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    override func mouseDown(with event: NSEvent) { gestes?.appui() }
    override func mouseDragged(with event: NSEvent) { gestes?.glisse() }
    override func mouseUp(with event: NSEvent) { gestes?.relache() }
    override func scrollWheel(with event: NSEvent) { gestes?.molette(event.scrollingDeltaY) }
    override func rightMouseDown(with event: NSEvent) { gestes?.clicDroit(event) }
}
```

```swift
import AppKit
import PokepetCore

/// Le cœur battant de l'app, deux minuteries :
/// - une fois par seconde, relire ~/.pokepet/ et demander au `Compagnon` quoi montrer ;
/// - 60 fois par seconde, avancer l'animation, la balade et le flash, et décider si les clics traversent.
@MainActor
final class Boucles {
    private let fenetre: NSWindow
    private let vue: VueSprite
    private let sprites: SourceSprites
    private let reglages: Reglages
    private let lecture: LectureDossier
    private var compagnon = Compagnon(lancement: Date())
    private(set) var apparence: Apparence?

    // L'animation en cours.
    private var courante: (mouvement: Mouvement, direction: Direction)?
    private var animation: AnimationChargee?
    private var lecteur = Lecteur(durees: [1], enBoucle: true)
    private var debut = Date()
    private var interludeEnCours = false
    private var debutFlash: Date?

    // La balade.
    private var pas: Pas?
    private var debutPas = Date()
    private var xDepart: CGFloat = 0
    private var hasard = SystemRandomNumberGenerator()
    var enGlisse = false

    private var minuteries: [Timer] = []

    init(fenetre: NSWindow, vue: VueSprite, sprites: SourceSprites, reglages: Reglages, lecture: LectureDossier) {
        self.fenetre = fenetre
        self.vue = vue
        self.sprites = sprites
        self.reglages = reglages
        self.lecture = lecture
    }

    func demarrer() {
        relire()
        placerFenetre()
        minuteries = [
            Timer.scheduledTimer(withTimeInterval: 1.0 / 60, repeats: true) { [weak self] _ in
                MainActor.assumeIsolated { self?.avancer() }
            },
            Timer.scheduledTimer(withTimeInterval: 1, repeats: true) { [weak self] _ in
                MainActor.assumeIsolated { self?.relire() }
            },
        ]
    }

    // MARK: Une fois par seconde

    private func relire() {
        let maintenant = Date()
        let sessions = lecture.sessions(maintenant: maintenant)
        let reponses = CompteurDuJour.total(lecture.compteurs(journee: Journee.cle(maintenant)))
        let nouvelle = compagnon.mettreAJour(
            maintenant: maintenant, urgence: EtatLePlusUrgent.calculer(sessions), reponses: reponses,
            derniereActivite: sessions.map(\.majLe).max())
        let especeChangee = nouvelle.espece != apparence?.espece
        apparence = nouvelle
        vue.bulle = nouvelle.bulle
        if especeChangee {
            ajusterTaille()
            courante = nil
        }
        if nouvelle.flash { debutFlash = maintenant }
        if let interlude = nouvelle.interlude { jouerUneFois(interlude) }
        if !nouvelle.peutSeBalader { pas = nil }
    }

    // MARK: 60 fois par seconde

    private func avancer() {
        let maintenant = Date()
        avancerBalade(maintenant)
        if interludeEnCours && lecteur.estFinie(apres: maintenant.timeIntervalSince(debut)) {
            interludeEnCours = false
        }
        if !interludeEnCours {
            let voulu = mouvementVoulu()
            if courante?.mouvement != voulu.mouvement || courante?.direction != voulu.direction {
                jouer(voulu.mouvement, direction: voulu.direction, enBoucle: true)
            }
        }
        if let animation, !animation.images.isEmpty {
            vue.image = animation.images[min(lecteur.image(apres: maintenant.timeIntervalSince(debut)), animation.images.count - 1)]
        }
        vue.flash = debutFlash.map { max(0, 1 - CGFloat(maintenant.timeIntervalSince($0)) / 0.5) } ?? 0
        let souris = vue.convert(fenetre.convertPoint(fromScreen: NSEvent.mouseLocation), from: nil)
        fenetre.ignoresMouseEvents = !(enGlisse || vue.toucheLeSprite(souris))
    }

    private func mouvementVoulu() -> (mouvement: Mouvement, direction: Direction) {
        if let pas, pas.deplacement != 0 { return (.walk, pas.deplacement > 0 ? .droite : .gauche) }
        return (apparence?.fond ?? .idle, .face)
    }

    private func jouer(_ mouvement: Mouvement, direction: Direction, enBoucle: Bool) {
        guard let espece = apparence?.espece else { return }
        animation = sprites.animationOuRepos(mouvement, espece: espece, direction: direction)
        lecteur = Lecteur(durees: animation?.durees ?? [1], enBoucle: enBoucle)
        debut = Date()
        courante = (mouvement, direction)
    }

    private func jouerUneFois(_ mouvement: Mouvement) {
        pas = nil
        jouer(mouvement, direction: .face, enBoucle: false)
        interludeEnCours = true
    }

    private func avancerBalade(_ maintenant: Date) {
        guard let apparence, apparence.peutSeBalader, !enGlisse, !interludeEnCours,
              let ecran = fenetre.screen ?? NSScreen.main
        else {
            pas = nil
            return
        }
        if pas == nil || maintenant.timeIntervalSince(debutPas) >= pas!.duree {
            xDepart = fenetre.frame.minX
            pas = Balade.prochainPas(
                x: xDepart, minimum: ecran.visibleFrame.minX, maximum: ecran.visibleFrame.maxX - fenetre.frame.width,
                hasard: &hasard)
            debutPas = maintenant
        }
        guard let pas, pas.duree > 0, pas.deplacement != 0 else { return }
        let avance = min(maintenant.timeIntervalSince(debutPas) / pas.duree, 1)
        fenetre.setFrameOrigin(CGPoint(x: xDepart + pas.deplacement * avance, y: fenetre.frame.minY))
    }

    // MARK: Taille et position

    /// La fenêtre prend la taille de la plus grande image du Pokémon, plus la place de la bulle ;
    /// le bas et le milieu restent en place.
    private func ajusterTaille() {
        guard let espece = apparence?.espece else { return }
        let images = Mouvement.allCases.compactMap { sprites.animation($0, espece: espece, direction: .face) }.flatMap(\.images)
        let largeur = CGFloat(images.map(\.width).max() ?? 32), hauteur = CGFloat(images.map(\.height).max() ?? 32)
        vue.echelle = CGFloat(reglages.taille * Reglages.pixelsParPoint)
        let taille = CGSize(width: largeur * vue.echelle, height: hauteur * vue.echelle + vue.hauteurBulle)
        let ancien = fenetre.frame
        fenetre.setFrame(CGRect(origin: CGPoint(x: ancien.midX - taille.width / 2, y: ancien.minY), size: taille), display: true)
    }

    /// À la position retenue si elle est sur un écran, sinon en bas à droite de l'écran principal.
    private func placerFenetre() {
        if let position = reglages.position, NSScreen.screens.contains(where: { $0.visibleFrame.contains(position) }) {
            fenetre.setFrameOrigin(position)
        } else if let ecran = NSScreen.main {
            fenetre.setFrameOrigin(CGPoint(x: ecran.visibleFrame.maxX - fenetre.frame.width - 20, y: ecran.visibleFrame.minY + 20))
        }
    }

    // MARK: Appelé par les gestes

    func clic() {
        if let lien = apparence?.lien {
            OuvrirConversation.ouvrir(lien)
        } else {
            jouerUneFois(.hop)
        }
    }

    func positionChoisie() {
        pas = nil
        reglages.position = fenetre.frame.origin
    }

    func changerTaille(facteur: Double) {
        reglages.taille *= facteur
        ajusterTaille()
    }

    func tailleNormale() {
        reglages.taille = 1
        ajusterTaille()
    }
}
```

```swift
import AppKit

/// Traduit la souris en actions : glisser déplace, la molette change la taille,
/// un clic ouvre la conversation qui attend (ou fait sauter le compagnon), le clic droit ouvre le menu.
@MainActor
final class Gestes {
    private let fenetre: NSWindow
    private unowned let vue: VueSprite
    private unowned let boucles: Boucles
    private var depart = CGPoint.zero
    private var origine = CGPoint.zero
    private var aGlisse = false

    init(fenetre: NSWindow, vue: VueSprite, boucles: Boucles) {
        self.fenetre = fenetre
        self.vue = vue
        self.boucles = boucles
    }

    func appui() {
        depart = NSEvent.mouseLocation
        origine = fenetre.frame.origin
        aGlisse = false
        boucles.enGlisse = true
    }

    func glisse() {
        let souris = NSEvent.mouseLocation
        let dx = souris.x - depart.x, dy = souris.y - depart.y
        // Moins de 3 points : c'est encore un clic qui tremble.
        if hypot(dx, dy) > 3 { aGlisse = true }
        if aGlisse { fenetre.setFrameOrigin(CGPoint(x: origine.x + dx, y: origine.y + dy)) }
    }

    func relache() {
        boucles.enGlisse = false
        if aGlisse {
            boucles.positionChoisie()
        } else {
            boucles.clic()
        }
    }

    func molette(_ delta: CGFloat) {
        guard delta != 0 else { return }
        boucles.changerTaille(facteur: 1 + Double(delta) * 0.01)
    }

    func clicDroit(_ evenement: NSEvent) {
        guard let apparence = boucles.apparence else { return }
        let menu = MenuContextuel.construire(apparence: apparence) { [weak boucles] in boucles?.tailleNormale() }
        NSMenu.popUpContextMenu(menu, with: evenement, for: vue)
    }
}
```

```swift
import AppKit
import PokepetCore

/// Le menu du clic droit : nom, stade, réponses du jour, « Taille normale », « Quitter ».
@MainActor
enum MenuContextuel {
    static func construire(apparence: Apparence, tailleNormale: @escaping @MainActor () -> Void) -> NSMenu {
        let menu = NSMenu()
        // Sans action, un élément est grisé : ce sont des informations.
        menu.addItem(NSMenuItem(title: apparence.espece.nom, action: nil, keyEquivalent: ""))
        menu.addItem(NSMenuItem(title: "Stade \(apparence.stade.rawValue)/3", action: nil, keyEquivalent: ""))
        menu.addItem(NSMenuItem(title: "Réponses aujourd'hui : \(apparence.reponses)", action: nil, keyEquivalent: ""))
        menu.addItem(.separator())
        menu.addItem(ElementMenu(titre: "Taille normale", action: tailleNormale))
        // Quitter sort avec le code 0 : le LaunchAgent ne le relance pas avant la prochaine session.
        menu.addItem(ElementMenu(titre: "Quitter Poképote") { NSApp.terminate(nil) })
        return menu
    }
}

/// Un élément de menu qui appelle une fonction quand on le choisit.
@MainActor
private final class ElementMenu: NSMenuItem {
    private let quandChoisi: @MainActor () -> Void

    init(titre: String, action: @escaping @MainActor () -> Void) {
        quandChoisi = action
        super.init(title: titre, action: #selector(choisi), keyEquivalent: "")
        target = self
    }

    required init(coder: NSCoder) {
        fatalError("non utilisé")
    }

    @objc private func choisi() {
        quandChoisi()
    }
}
```

```makefile
# Le build système par défaut de SwiftPM 6.4 échoue avec les seuls Command Line Tools
# (« Unknown error parsing property list ») : on prend l'ancien, « native ».
SWIFT_FLAGS = --build-system native
# Swift Testing est livré dans les Command Line Tools, mais il faut dire où.
FW = $(shell xcode-select -p)/Library/Developer/Frameworks
TEST_FLAGS = $(SWIFT_FLAGS) -Xswiftc -F -Xswiftc $(FW) -Xlinker -F -Xlinker $(FW) -Xlinker -rpath -Xlinker $(FW)

.PHONY: test test-app test-mod run app install uninstall
test: test-app test-mod

test-app:
	swift test $(TEST_FLAGS)

# `claude plugin test` ne cherche les tests que dans le dossier du mod, et refuse les imports
# qui en sortent : on assemble une copie du mod avec tests/mod/ dedans, dans un dossier temporaire.
# Les tests importent donc ../../../hooks/… (le chemin dans cette copie).
test-mod:
	@T=$$(mktemp -d) && cp -R mod $$T/mod && mkdir -p $$T/mod/tests && cp -R tests/mod $$T/mod/tests/mod \
	  && claude plugin validate $$T/mod && claude plugin test $$T/mod; S=$$?; rm -rf $$T; exit $$S

# Lance l'app depuis le dépôt, sans l'installer (Ctrl-C pour arrêter).
run:
	swift build $(SWIFT_FLAGS)
	POKEPET_SPRITES=$(CURDIR)/sprites/pmd .build/debug/Pokepote

# Assemble .build/Poképote.app : le binaire, sa fiche, les sprites, une signature locale.
APP_BUILD = .build/Poképote.app
app:
	swift build $(SWIFT_FLAGS) -c release
	rm -rf "$(APP_BUILD)" && mkdir -p "$(APP_BUILD)/Contents/MacOS" "$(APP_BUILD)/Contents/Resources"
	cp .build/release/Pokepote "$(APP_BUILD)/Contents/MacOS/"
	cp packaging/Info.plist "$(APP_BUILD)/Contents/"
	cp -R sprites "$(APP_BUILD)/Contents/Resources/"
	codesign --force --sign - "$(APP_BUILD)"

# À lancer depuis le dépôt principal (pas un worktree) : le mod est installé depuis ce dossier.
APP = $(HOME)/Applications/Poképote.app
LABEL = com.hn6pot.pokepote
AGENT = $(HOME)/Library/LaunchAgents/$(LABEL).plist
install: test app
	mkdir -p $(HOME)/Applications $(HOME)/Library/LaunchAgents
	launchctl bootout gui/$$(id -u)/$(LABEL) 2>/dev/null || true
	rm -rf "$(APP)" && cp -R "$(APP_BUILD)" "$(APP)"
	sed 's|@BINAIRE@|$(APP)/Contents/MacOS/Pokepote|' packaging/$(LABEL).plist > $(AGENT)
	launchctl bootstrap gui/$$(id -u) $(AGENT)
	claude plugin marketplace add $(CURDIR) 2>/dev/null || claude plugin marketplace update pokepet
	claude plugin install pokepet@pokepet --scope user 2>/dev/null || claude plugin update pokepet@pokepet --scope user

uninstall:
	launchctl bootout gui/$$(id -u)/$(LABEL) 2>/dev/null || true
	rm -f $(AGENT)

	claude plugin marketplace remove pokepet 2>/dev/null || true
```
